# Library Management System (C)

Sistem menaxhimi biblioteke në C — shtim librash, kërkim sipas autorit/titullit dhe statistika.

`C`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/Library-Management-System/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

## ▶️ Ekzekutimi origjinal
Kompilo me `gcc libraryMS.c -o library` dhe ekzekuto `./library`.
